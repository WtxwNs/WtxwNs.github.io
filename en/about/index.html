About

A slightly personal academic homepage for research, writing, and useful links.

Tongxi Wang studies AI theory, reinforcement learning, multi-agent systems, efficient language models, and robotics. This site keeps research outputs, project records, and short notes in one maintainable place.

I like problems where a small geometric observation changes the stability story.

Tools

Astro, TypeScript, Tailwind CSS, MDX, Astro Content Collections, and static deployment.

Source and Deployment

The site is static-site friendly and can be deployed to Vercel or GitHub Pages.
